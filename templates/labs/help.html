Installing the lab root certificate

Download http://netsec.internal/ca.crt while on the lab network, then:

  • Windows: double-click the file → Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities.
  • macOS: double-click to add it to Keychain Access (login keychain), open it, expand Trust, set When using this certificate to Always Trust.
  • Linux (Ubuntu): sudo cp ca.crt /usr/local/share/ca-certificates/te451.crt && sudo update-ca-certificates. Firefox keeps its own store: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

Only trust a root CA like this one when you know exactly who runs it. Remove it at the end of the semester.

How labs work

  • Your numbers, files and keys are generated just for you. Discuss ideas with classmates; never copy answers. They wouldn't match anyway.
  • Timed labs start a countdown when you press Start. It keeps running if you close the browser.
  • Open labs can be worked on in several sittings until the deadline.
  • Short written answers are graded by a TA. You can update them until the lab closes.
  • Need extra time for a valid reason? Talk to the lecturer or a TA before the deadline.
